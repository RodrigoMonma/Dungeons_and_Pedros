# Dungeons_and_Pedros
----------------------------------------------------
Projeto avaliativo em C criado por:
- Rodrigo Ryoji Oliveira Monma
- Pedro Augusto Leão Queiroz
----------------------------------------------------
A história consiste no personagem que se chama Pedro cujo objetivo é comprar pão de forma, mas só é possível adquirir numa masmorra ao lado de sua vila.

-----------------------------------------------------
Comandos:
- | WASD | : andar
- | O |   : atacar
- | I |   : interagir

-----------------------------------------------------
Simbolos e seus significados:

- | * | : parede
- | # | : espinho
- | L | : proxima sala
- | k | : caixa
- | @ | : chave
- | O | : botao
- | D | : porta fechada
- | = | : porta aberta
- | v | : jogador e npc
- | X | : inimigo 1
- | Y | : inimigo 2
- | Z | : chefao (mofo)
